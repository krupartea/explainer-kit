# Benchmarks

Fixed briefs, one per topic, reused unchanged by every kit version so videos can be compared. A run copies
`<topic>.md` into a new video folder as `brief.md`.

| topic | set | how its feedback may enter the kit |
|---|---|---|
| `nms.md` | training | as general rules, and its lines may serve as the rules' examples |
| `sift.md` | validation | as general rules only; never as examples, and nothing specific to SIFT |

A kit change counts as an improvement when the validation videos get better. Rotate in a fresh validation
topic from time to time: watching the same one repeatedly turns it into training data.
